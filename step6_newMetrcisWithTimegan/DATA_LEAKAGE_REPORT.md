# 数据泄漏分析报告

## 执行日期
2026-01-09

## 关键发现

### 🚨 严重数据泄漏确认

**TimeGAN训练时看到了15.9%的测试集数据**

- TimeGAN训练数据: 209个原始flights（全部原始数据）
- 测试集: 252个flights
- **重叠: 40个flights (15.9%)**
- 这40个flights的模式被TimeGAN学习，然后用于测试

## 泄漏路径分析

### 错误的数据流程（当前实现）

```
步骤1: 提取数据
  └─ 从flights.csv提取全部209个正常flights
  
步骤2: 训练TimeGAN  ⚠️ 泄漏发生点
  └─ 使用全部209个flights训练TimeGAN
     (包含了后来要用作测试的flights)
  
步骤3: 生成合成数据
  └─ TimeGAN生成1045个合成flights
     (这些合成数据包含了测试flights的模式)
  
步骤4: 数据集划分  ⚠️ 为时已晚
  └─ Train: 752 flights (209原始 + 543合成)
  └─ Val: 250 flights
  └─ Test: 252 flights (其中40个已被TimeGAN"见过")
  
步骤5: 模型训练
  └─ 7个模型在TimeGAN增强数据上训练
     (所有模型都学到了测试flights的模式)
  
步骤6: 测试  ✗ 结果无效
  └─ 在"见过"的flights上测试
  └─ 所有模型97.9%窗口预测一致
  └─ DR@Δt完全相同
```

### 正确的数据流程（应该实现）

```
步骤1: 先划分原始数据  ✓ 关键
  └─ 从209个flights中划分:
     - Train flights: ~125个 (60%)
     - Val flights: ~42个 (20%)
     - Test flights: ~42个 (20%)
  
步骤2: 训练TimeGAN  ✓ 只用训练集
  └─ 仅使用Train flights训练TimeGAN
     (完全不看Test flights)
  
步骤3: 生成合成数据  ✓ 基于训练集
  └─ 在Train flights的模式上生成合成数据
     (扩充训练集，不泄漏测试信息)
  
步骤4: 合并训练数据
  └─ Train = 原始Train flights + 合成flights
  
步骤5: 模型训练  ✓ 纯净训练集
  └─ 模型从未见过Test flights
  
步骤6: 测试  ✓ 有效测试
  └─ Test flights对模型完全陌生
  └─ 结果反映真实泛化能力
```

## 影响分析

### 对实验结果的影响

1. **人为提高的性能**
   - 模型在训练时"记住"了40个测试flights的模式
   - 测试时遇到这些flights会触发"记忆"
   - 性能指标不代表真实泛化能力

2. **模型高度一致的原因**
   - 所有7个模型都在相同的泄漏数据上训练
   - 都学到了测试集的相同模式
   - 97.9%的攻击窗口预测一致是因为都"记住"了
   - DR@Δt完全相同是因为在"见过"的数据上表现一致

3. **论文发表的障碍**
   - 数据泄漏是严重的方法论错误
   - 审稿人会拒稿
   - 结果无法证明方法的有效性

### 为什么所有模型DR完全相同？

**现在可以解释了：**

```
原因1: 数据泄漏
  - TimeGAN学习了测试集模式
  - 所有模型都在泄漏数据上训练
  - 都"记住"了测试flights的特征
  
原因2: 测试集太小
  - 只有12个攻击实例
  - 其中可能多个来自"泄漏"的40个flights
  - 模型轻易识别"见过"的模式
  
原因3: 合成数据的影响
  - TimeGAN生成的1045个合成flights
  - 包含了测试集模式的变体
  - 强化了对测试集模式的记忆
```

## 实验结果的可信度

### ❌ 不可信的指标
- **DR@Δt**: 所有模型完全相同（83.3%/91.7%/100%）
- **检测延迟**: 所有模型在同一时刻检测（数据泄漏导致）
- **攻击窗口预测**: 97.9%一致（记忆效应）
- **整体准确率**: 被人为提高

### ⚠️ 部分可信的指标
- **MTBFA**: 不同模型有差异（TCN 1.37h vs Transformer 0.53h）
- 说明模型在正常数据的误报率上仍有差异
- 但也可能受泄漏影响

### ✓ 可能可信的发现
- TimeGAN能生成合理的合成数据（如果没有泄漏）
- 不同模型架构在误报控制上有差异
- 时间感知指标的计算方法是正确的
