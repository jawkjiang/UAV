# 测试集规模不足导致模型性能无法区分的问题分析

## 🔴 核心问题

### 1. 测试集太小
- **总攻击数**: 仅51个
- **每种攻击类型**: 12-13个样本
- 这导致统计显著性严重不足

### 2. DR@5s完全相同的原因
所有模型在5秒内都检测到了**48/51**个攻击：
```
48 / 51 = 0.941 (94.1%)
```

这是一个**离散化问题**：
- 只检测到3个不同的攻击数量差异
- 在如此小的测试集上，无法体现模型细微差异

## ✅ 实际存在的性能差异

### 1. DR@1s 有显著差异 (15.7% - 35.3%)
```
TRANSFORMER : 35.3% (18/51)  ⭐ 最好
LSTM/BiLSTM/GRU : 29.4% (15/51)
CNN/CNN_LSTM : 27.5% (14/51)
TCN : 15.7% (8/51)  ⚠️ 最差
```

### 2. DR@2s 有明显差异 (62.7% - 78.4%)
```
Most models : 78.4% (40/51)  ⭐
TCN : 62.7% (32/51)  ⚠️
```

### 3. ADD (平均检测延迟) 有差异 (1.67s - 2.10s)
```
TRANSFORMER : 1.673s  ⭐ 最快
LSTM : 1.688s
BiLSTM : 1.688s
GRU : 1.688s
CNN : 1.719s
CNN_LSTM : 1.719s
TCN : 2.101s  ⚠️ 最慢
```

### 4. 不同攻击类型表现差异
- **STEP**: 所有模型 1.3-1.5s
- **DRIFT**: LSTM/Transformer (1.46s) vs TCN (2.42s)
- **DELAY**: LSTM/Transformer (1.28s) vs TCN (2.06s)
- **TAKEOVER**: 所有模型都较慢 (2.47-2.59s)

## 💡 论文写作建议

### 方案A: 强调早期检测能力 ✅ 推荐

**重点突出 DR@1s 和 DR@2s**：
```
"在关键的早期检测阶段（≤2秒），模型性能存在显著差异：
- Transformer在1秒内检测率达35.3%，优于其他模型
- TCN的早期检测能力较弱，DR@1s仅15.7%
- 在2秒阈值下，差距进一步扩大（TCN: 62.7% vs 其他: 78.4%）"
```

### 方案B: 增加更细粒度的时间阈值

修改 `config.py`:
```python
DELTA_T_VALUES = [0.5, 1, 1.5, 2, 3, 5, 10, 15, 30]
```

这样可以得到更多区分点。

### 方案C: 强调延迟分布差异

```
"虽然最终检测率相近（DR@5s: 94.1%），但检测延迟分布存在显著差异：
- Transformer平均延迟1.67s（中位数1.18s）
- TCN平均延迟2.10s（中位数1.71s），比Transformer慢25.5%"
```

### 方案D: 按攻击类型分析

```
"不同攻击类型暴露了模型的特定弱点：
- DRIFT攻击: TCN (2.42s) vs LSTM (1.46s)，差距66%
- TAKEOVER攻击: 所有模型均表现较差（>2.4s），这是未来改进方向"
```

## 🎯 解决测试集不足的方法

### 方法1: 使用完整测试集（如果有）

检查step5是否有更大的测试集：
```bash
# 查看是否有test_complete.csv或其他测试数据
ls ../step5_timegan/output/test*.csv
```

### 方法2: 使用交叉验证

如果训练集足够大，可以做k-fold交叉验证获得更稳定的性能估计。

### 方法3: Bootstrap重采样

对51个攻击进行bootstrap重采样，估计置信区间：
```python
# 例如：DR@1s的95%置信区间
# Transformer: 35.3% [22.5%, 48.2%]
# TCN: 15.7% [7.8%, 27.5%]
```

### 方法4: 增加测试数据

如果可能，生成更多测试攻击样本（每种攻击至少50-100个）。


### 2. 箱线图
展示延迟分布的差异（中位数、四分位数、异常值）。

### 3. Per-Attack-Type Radar Chart
每种攻击类型的DR@不同阈值，用雷达图展示。

## 结论

**当前问题**：测试集太小（51个攻击）导致DR@5s无法区分模型。

**实际情况**：模型在早期检测（DR@1s, DR@2s）和延迟分布上**有显著差异**。

**论文策略**：
1. 强调早期检测能力的差异（DR@1s: 15.7%-35.3%）
2. 使用延迟分布和ADD作为主要区分指标
3. 按攻击类型分析性能
4. 使用统计方法（置信区间）说明差异显著性
5. 承认测试集规模限制，作为future work提出

**是否需要改变攻击比例**：
- ❌ 不建议：这会改变数据分布，使结果不可比
- ✅ 建议：增加测试样本数量（如果可能）
- ✅ 建议：使用更细粒度的时间阈值
